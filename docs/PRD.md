# 휠 메모 — 제품 요구사항 문서(PRD)

- 문서 상태: 구현 기준 초안
- 대상 플랫폼: iPhone
- 첫 출시 언어: 한국어
- 제품 한 문장: 생각을 바로 적고, 메모를 폴더나 임시저장 쪽으로 던지듯 드래그해 정리하는 메모 앱

## 1. 제품 목표

휠 메모는 메모를 시작하기 전에 제목이나 폴더를 고르게 하지 않는다. 앱을 열면 바로 글을 쓸 수 있고, 작성이 끝나면 메모 카드를 원형으로 펼쳐진 폴더 중 하나로 드래그해 저장한다. 폴더에 넣기 전이라면 같은 드래그 동작으로 임시저장할 수도 있다. 새 메모는 현재 메모를 드롭해 작성 화면을 비운 뒤 시작한다.

### 주요 사용자

떠오른 생각을 놓치기 전에 기록하고 싶지만, 기록 전에 분류부터 해야 하는 흐름은 부담스러운 사람.

### 제품이 해결할 문제

1. 메모 앱을 열고 새 메모를 찾는 데 걸리는 단계를 줄인다.
2. 메모를 작성한 뒤 폴더를 찾아 이동하는 과정을 하나의 자연스러운 동작으로 만든다.
3. 작성 도중 앱을 떠나거나 새 메모를 시작해도 내용을 잃지 않게 한다.
4. 짧은 할 일을 홈 화면에서 바로 확인하고 완료할 수 있게 한다.

### 첫 버전의 성공 조건

- 앱을 열자마자 메모를 작성하거나 최근 임시저장 메모를 이어서 작성할 수 있다.
- 새 메모를 폴더 또는 임시저장으로 드롭하면 빈 작성 화면에서 다음 메모를 시작할 수 있다.
- 메모의 저장·이동 대상이 드래그 중 분명히 보이고, 잘못된 드롭을 쉽게 취소할 수 있다.
- 오프라인 작성 내용이 보존되고 연결이 돌아오면 iCloud와 동기화된다.
- 위젯에서 투두를 체크하면 앱을 열지 않아도 완료 처리된다.

## 2. 범위와 용어

### 포함

- 텍스트 메모와 일반 메모의 사진 첨부
- 기본 폴더와 사용자 폴더 관리
- 원형 폴더 선택 휠을 통한 저장 및 이동
- 임시저장, 검색, 폴더별 고정, 휴지통 및 30일 복구
- 텍스트 전용 투두리스트와 홈 화면 위젯
- 기기 내 저장, 오프라인 사용, iCloud 자동 동기화

### 제외

- 즐겨찾기 및 즐겨찾기 폴더
- Android, 웹, iPad 전용 화면
- 서식 있는 글 편집, 태그, 공동 편집, 메모 공유
- 투두 알림, 마감일, 반복 일정, 우선순위
- 별도 회원가입 또는 자체 서버 계정

### 용어

| 용어 | 의미 |
| --- | --- |
| 작성 화면 | 앱의 기본 화면. 새 메모나 기존 메모를 편집하는 곳 |
| 일반 메모 | 글과 사진을 담을 수 있는 메모 |
| 투두 메모 | 투두리스트에 속한 한 줄짜리 텍스트 메모. 한 메모가 한 할 일 |
| 인사이트 | 사용자 폴더로 분류하지 않을 메모를 저장하는 기본 폴더 |

## 3. 정보 구조와 화면

### 3.1 작성 화면

- 앱의 첫 화면은 작성 화면이다. 불필요한 환영 화면이나 폴더 선택 단계를 거치지 않는다.
- 좌측 상단에는 원형 햄버거 버튼, 우측 상단에는 세로 점 세 개(⋮) 모양의 케밥 메뉴 버튼을 둔다. 별도의 새 메모 버튼은 두지 않는다.
- 중앙의 메모 카드에서 글을 작성한다. 일반 메모에는 케밥 메뉴의 사진 첨부 항목을 통해 iPhone의 사진 선택 흐름으로 사진을 첨부할 수 있다.
- 텍스트 입력·선택·스크롤과 메모 카드 드래그가 충돌하지 않도록 드래그를 시작할 수 있는 영역을 분명히 제공한다. 드래그가 시작되면 카드 전체가 이동하는 것처럼 보이게 한다.
- 임시저장 메모가 있으면 마지막으로 수정한 메모를 이어서 보여준다. 없으면 빈 메모 카드를 보여준다.
- 내용이 전혀 없는 빈 카드는 임시저장 목록에 생성하지 않는다.

### 3.2 작성 모드와 정리 모드

- 작성 화면은 **작성 모드**와 **정리 모드** 두 상태로 동작한다.
- 앱을 열면 작성 모드로 시작한다. 작성 모드에서는 텍스트 입력·선택·커서 이동·본문 스크롤이 가능하다.
- 사용자가 메모 입력을 시작하면 우측 상단 케밥 메뉴 버튼 아래 **완료** 버튼을 표시한다. 내용이 전혀 없는 빈 메모에서는 완료 버튼을 표시하지 않는다.
- 완료 버튼을 누르면 키보드를 닫고 정리 모드로 전환한다. 이때 상단 **완료** 버튼은 사라지고, 정리된 메모 카드 우측 상단에 **편집** 버튼을 표시한다.
- 카드 우측 상단의 **편집** 버튼 왼쪽에는 메모 시간을 표시한다. 기준 시각은 생성 시각과 마지막 수정 시각 중 더 최근 시각이며, 메모를 수정하면 갱신한다. 날짜와 시각은 기기의 현지 형식으로 보여준다.
- 정리 모드에서는 작성 완료한 메모 카드에 테두리가 생기고 텍스트 입력·선택·커서 이동을 허용하지 않는다. 메모 카드 위에서 시작한 드래그 제스처는 본문 스크롤이 아니라 메모 카드 이동으로 처리한다.
- 메모 카드 높이는 고정하지 않고 텍스트의 실제 표시 높이에 맞춰 유동적으로 결정한다. 테두리는 첫 줄 위와 마지막 줄 아래에 작은 여백만 두고 내용을 감싸며, 화면을 채우기 위한 빈 공간을 추가하지 않는다. 줄바꿈과 글씨 크기 변화도 카드 높이에 반영한다. 좌우 폭과 여백은 별도로 유지한다.
- 정리 모드에서 메모 카드를 드래그하기 시작하면 폴더 휠을 표시한다. 사용자는 드래그 방향으로 저장·이동·임시저장·삭제 대상을 선택한다.
- 폴더, 임시저장 또는 삭제 대상에서 손을 놓으면 해당 동작을 실행하고 빈 작성 화면으로 이동한다.
- 어느 대상에도 속하지 않는 곳에서 손을 놓거나 드래그가 취소되면 메모 카드를 원위치로 돌리고 정리 모드를 유지한다.
- 정리 모드에서 카드 우측 상단의 **편집** 버튼을 누르면 작성 모드로 돌아간다. 카드의 편집 버튼은 사라지고 상단에 **완료** 버튼이 다시 표시되며, 기존 내용과 커서 편집을 이어갈 수 있다.

### 3.3 케밥 메뉴(⋮)

- 우측 상단 버튼을 누르면 현재 화면에 맞는 작업과 설정 진입점을 한곳에 보여준다.
- 작성 중인 일반 메모에서는 **사진 첨부**, 내용이 있는 메모에서는 **삭제**, 폴더에 저장된 메모에서는 **고정/고정 해제**를 제공한다.
- **설정**은 항상 접근할 수 있다. 설정 화면에는 iCloud 동기화 상태와 여러 앱 동작을 관리하는 항목을 모은다.
- 상황에 맞지 않는 항목은 표시하지 않는다. 예를 들어 투두 메모에는 사진 첨부를, 빈 작성 화면에는 삭제를 표시하지 않는다.
- **새 메모** 항목은 제공하지 않는다. 새 메모를 시작하려면 현재 메모를 폴더, 임시저장 또는 삭제 대상으로 드롭해야 한다. 삭제는 휠에서 드롭하거나 케밥 메뉴의 삭제 항목으로 실행할 수 있다.

### 3.4 서랍 메뉴

좌측 상단 버튼을 누르면 서랍이 열리며 다음 항목을 보여준다.

1. 작성 화면
2. 인사이트
3. 투두리스트
4. 임시저장
5. 휴지통
6. 사용자가 만든 폴더들
7. 검색 진입점(하단 고정 바)

폴더 목록에서는 메모의 첫 줄 또는 미리보기, 사진 유무, 수정 시각, 고정 상태를 파악할 수 있어야 한다. 폴더 안에서는 고정한 메모를 위에 표시한다.

### 3.5 임시저장 화면

- 임시저장 메모를 최근 수정 순으로 보여준다.
- 항목을 누르면 작성 화면에서 이어서 편집한다.
- 임시저장 메모를 폴더 휠로 저장하면 임시저장 목록에서 제거한다. 메모를 중복 생성하지 않는다.
- 임시저장 메모를 휴지통으로 옮길 수 있다.

### 3.6 휴지통 화면

- 삭제한 메모와 삭제한 사용자 폴더를 구분해 보여준다.
- 삭제 날짜와 영구 삭제 예정 시점을 확인할 수 있다.
- 개별 메모 또는 폴더를 30일 안에 복구할 수 있다.

## 4. 메모와 폴더 규칙

### 4.1 기본 폴더

- 기본 폴더는 **인사이트**와 **투두리스트** 두 개다.
- 두 폴더는 사용자가 만들 필요 없이 처음부터 존재하며 삭제할 수 없다.
- 인사이트는 사용자 폴더를 지정하지 않고 저장하려는 일반 메모의 목적지다. 사용자가 휠에서 인사이트를 직접 선택한다.
- 폴더를 선택하지 않고 드롭을 취소한 메모는 인사이트에 자동 저장하지 않는다. 작성 화면과 내용을 그대로 유지한다.

### 4.2 사용자 폴더

- 사용자는 서랍에서 폴더를 만들고 이름을 바꾸고 삭제할 수 있다.
- 활성 폴더는 기본 폴더를 포함해 최대 **12개**다. 따라서 사용자 폴더는 최대 10개다.
- 임시저장과 휴지통은 별도 공간이며 12개 제한에 포함하지 않는다.
- 폴더를 삭제하면 폴더 자체와 안의 모든 메모가 함께 휴지통으로 이동한다.
- 삭제한 폴더를 복구하면 그 안의 메모도 함께 복구한다.
- 폴더 이름은 빈 문자열을 허용하지 않는다. 같은 위치에서 구별하기 어려운 중복 이름은 만들지 않도록 안내한다.

### 4.3 일반 메모

- 일반 메모는 글과 사진을 담을 수 있다. 글이 없고 사진만 있는 메모도 허용한다.
- 저장된 메모에는 한 시점에 하나의 주 폴더만 있다.
- 별도 제목 입력은 요구하지 않는다. 목록에서는 첫 줄을 제목처럼 사용하고, 첫 줄이 없으면 사진 메모임을 알 수 있는 기본 이름을 표시한다.
- 폴더별로 메모를 고정하거나 고정을 해제할 수 있다. 고정한 메모는 해당 폴더의 상단에 표시한다.
- 기존 메모를 수정한 내용은 원래 메모에 저장한다. 같은 메모의 복제본을 만들지 않는다.
- 기존 메모를 다른 폴더로 드롭하면 해당 폴더로 이동한다. 고정 상태는 이동 후 새 폴더에서 혼동을 피하도록 해제한다.

### 4.4 투두 메모

- 투두리스트에 있는 메모 하나가 체크할 일 하나다.
- 투두 메모는 **사용자가 보는 문자 기준 최대 30자**, 한 줄, 텍스트 전용이다. 사진 첨부와 줄바꿈은 허용하지 않는다.
- 일반 메모를 투두리스트로 옮길 때 글이 30자를 넘거나 줄바꿈·사진이 있으면 드롭을 거부하고 이유를 보여준다. 원본 메모와 작성 내용은 유지한다.
- 투두리스트에서도 메모를 열어 글을 수정하고 다른 폴더로 이동할 수 있다.
- 투두를 완료하면 해당 메모는 즉시 휴지통으로 이동한다. 앱과 위젯에서 같은 규칙을 적용한다.
- 완료된 투두를 복구하면 다시 미완료 상태로 투두리스트에 나타난다.

## 5. 핵심 상호작용: 폴더 휠

### 5.1 열림과 배치

1. 사용자가 메모 카드를 좌 혹은 우측으로 드래그하기 시작하면 현재 저장 가능한 폴더 아이콘이 한 원형 휠에 나타난다.
2. 활성 폴더는 최대 12개 모두 같은 휠에서 접근할 수 있다. 페이지를 나누거나 드래그 도중 다른 페이지로 이동하지 않는다.
3. 휠의 **11시~1시 상단 영역**을 기본 작업에 고정 배정한다. 이 영역에는 폴더를 놓지 않는다.
4. 아직 폴더에 저장되지 않은 메모에서는 **11시 임시저장**, **1시 삭제**를 보여준다. 임시저장 목록에서 다시 연 미분류 메모에도 같은 배치를 적용한다.
5. 이미 폴더에 저장된 메모에서는 **12시 삭제**만 보여준다. 11시 임시저장 대상은 나타나지 않는다. 저장된 메모는 현재 폴더에 드롭해 편집을 마치거나 다른 폴더로 드롭해 이동할 수 있다.
6. 폴더 아이콘은 1시에서 시계 방향으로 11시까지 이어지는 **나머지 300도 원호**에 일정한 각도 간격으로 배치한다. 폴더가 하나면 6시, 두 개면 약 3시 30분·8시 30분에 놓는다. 구현 시 폴더가 N개라면 각 폴더 중심 각도를 `30° + (순서 + 0.5) × 300° / N`으로 계산한다. 여기서 12시는 0도이고 시계 방향으로 증가한다.
7. 같은 폴더 수와 정렬 순서라면 새 메모와 기존 메모에서 **폴더 아이콘 위치가 완전히 같아야 한다**. 상단 작업의 개수나 위치가 바뀌어도 폴더 위치를 재계산하지 않는다.
8. 폴더가 많아져도 한 원을 유지한다. 아이콘 자체의 좁은 영역만으로 드롭을 판단하지 않고, 중심에서 드래그한 방향의 각도 구역으로 대상을 선택한다. 선택된 폴더만 이름과 아이콘을 크게 강조해 현재 대상을 알아볼 수 있게 한다.

### 5.2 조준과 드롭

- GTA의 무기 선택 휠처럼 현재 가리키는 방향을 즉시 알 수 있어야 한다.
- 드래그한 메모가 폴더의 선택 영역에 들어오면 해당 아이콘을 약간 키우고 이름을 또렷하게 보여준다.
- 선택 대상에 처음 들어가거나 다른 대상으로 바뀔 때 짧은 햅틱을 준다. 한 대상 안에서 움직이는 동안 햅틱을 계속 반복하지 않는다.
- 아이콘 그림보다 넓은 선택 영역을 사용하되 이웃 폴더의 영역과 겹치지 않게 한다.
- 폴더 위에서 손을 놓으면 저장 또는 이동을 확정한다. 성공을 짧은 모션과 햅틱으로 알린 뒤 빈 작성 화면을 보여준다.
- 미분류 메모를 11시 임시저장 대상에 놓으면 임시저장 목록에 보관하고 빈 작성 화면을 보여준다. 기존 임시저장 메모를 다시 열어 이 대상으로 놓으면 같은 메모를 갱신하며 중복 생성하지 않는다.
- 미분류 메모를 1시 삭제 대상 또는 저장된 메모를 12시 삭제 대상에 놓으면 휴지통으로 이동하고 빈 작성 화면을 보여준다. 삭제 대상은 색과 아이콘으로 분명히 구별하고, 30일 안에 복구할 수 있다.
- 어느 대상에도 속하지 않는 곳에서 손을 놓거나 제스처가 취소되면 저장·이동·삭제하지 않는다. 메모 카드를 원위치로 돌리고 내용도 유지한다.
- 투두리스트의 제한을 위반하는 메모를 투두리스트 쪽으로 가져가면 저장 불가 상태를 미리 표시한다. 그 상태로 놓아도 원본을 잃지 않는다.

### 5.3 사용성과 접근성

- 애니메이션은 빠르되 급하지 않게 하고, 드래그 중 프레임 끊김이나 갑작스러운 아이콘 재배치가 없도록 한다.
- 키보드가 열린 상태와 닫힌 상태, 작은 iPhone 화면과 큰 글씨 설정에서도 폴더가 화면 밖으로 잘리지 않게 배치한다.
- 사용자가 시스템에서 동작 줄이기를 켠 경우 과한 확대·이동을 줄인다.
- VoiceOver와 드래그 사용이 어려운 상황을 위해 동일한 폴더를 선택할 수 있는 목록 방식도 제공한다. 이는 폴더 휠을 대체하는 기본 경험이 아니라 접근 가능한 대안이다.

## 6. 작성, 임시저장, 새 메모

### 6.1 새 메모 작성

1. 사용자는 앱을 열자마자 입력할 수 있다.
2. 작성 중인 내용은 입력에 따라 기기에 안전하게 보존한다. 이 자동 보존은 드래그로 임시저장을 확정하는 동작과 구별한다.
3. 폴더에 드롭하면 선택한 폴더에 저장한다. 이전에 임시저장 목록에 있던 메모라면 그 목록에서는 제거한다.
4. 11시 임시저장에 드롭하면 폴더를 배정하지 않고 임시저장 목록에 보관한다. 1시 삭제에 드롭하면 휴지통으로 옮긴다.
5. 폴더, 임시저장 또는 삭제 대상으로 드롭을 마치면 빈 작성 화면을 보여준다. 사용자는 곧바로 다음 메모를 쓸 수 있다.

### 6.2 새 메모로 전환하는 규칙

- 작성 중인 새 메모에는 별도의 새 메모 버튼이나 메뉴 항목이 없다. 폴더·임시저장·삭제 중 하나로 드롭을 완료하는 것이 다음 빈 메모로 넘어가는 동작이다.
- 기존 임시저장 메모를 다시 열어 폴더에 저장하거나 임시저장으로 드롭해도 같은 규칙을 따른다.
- 저장된 메모를 편집한 뒤 다른 폴더 또는 현재 폴더에 드롭하면 수정 내용을 저장하고 빈 작성 화면으로 이동한다.
- 메모를 계속 작성하려면 드롭하지 않고 작성 화면에 머문다. 휠에서 대상 밖에 놓으면 드래그만 취소된다.
- 메모를 버리려면 휠 상단의 삭제 대상으로 드롭하거나 케밥 메뉴에서 삭제를 명시적으로 선택한다. 삭제한 메모에는 휴지통의 30일 복구 규칙을 적용하고 빈 작성 화면을 보여준다.
- 사진과 글이 모두 없는 빈 작성 화면에서는 드래그 저장·삭제를 실행하지 않는다.

### 6.3 앱 이탈과 재실행

- 작성 도중 앱을 닫거나 시스템이 앱을 종료하면 아직 폴더에 넣지 않은 내용을 자동으로 임시저장한다. 이때 선택 화면을 요구하지 않는다.
- 재실행 시 가장 최근에 수정한 임시저장 메모를 작성 화면에 보여준다.
- 임시저장 메모가 여럿이면 나머지는 서랍의 임시저장 목록에서 열 수 있다.
- 앱 종료 시 사진을 포함한 메모가 일부만 저장되는 일이 없도록 한다.

## 7. 검색, 삭제, 복구

### 7.1 검색

- 저장된 일반 메모, 투두 메모, 임시저장 메모의 텍스트를 검색한다.
- 결과에는 메모 미리보기와 현재 위치를 표시한다. 결과를 눌러 해당 메모를 열 수 있다.
- 휴지통은 일반 검색에서 제외한다.
- 검색어가 없거나 결과가 없을 때 각각 이해하기 쉬운 빈 화면을 보여준다.

### 7.2 휴지통

- 휠 상단 또는 케밥 메뉴에서 삭제한 메모, 완료한 투두, 삭제한 사용자 폴더를 담는다.
- 삭제 시각부터 30일간 보관하고 이후 영구 삭제한다.
- 30일 안에는 메모 또는 폴더를 복구할 수 있다. 폴더를 복구하면 그 안의 메모도 함께 돌아온다.
- 개별 메모는 원래 폴더로 복구한다. 원래 폴더가 더는 없으면 인사이트로 복구하고 위치 변경을 알려준다.
- 이미 삭제된 폴더의 메모를 복구해야 할 때는 폴더 복구를 먼저 안내한다.
- 영구 삭제 대상은 기기와 iCloud의 동기화 대상에서도 제거한다.

## 8. 홈 화면 투두 위젯

- iPhone 홈 화면 위젯에 투두리스트의 미완료 메모를 체크박스가 있는 목록으로 표시한다.
- 각 투두는 정확히 한 줄로 표시한다. 실제 화면 폭과 글씨 크기 때문에 전체 문장을 보여줄 수 없으면 말줄임표를 사용한다. **30자 제한만으로 모든 위젯 크기에서 한 줄 표시가 보장되는 것은 아니므로** 줄 제한도 별도로 적용한다.
- 위젯에서 체크박스를 누르면 앱을 열지 않고 완료되며, 항목은 위젯에서 사라지고 휴지통으로 이동한다.
- 위젯에서 처리한 결과는 앱의 투두리스트와 일치해야 한다. 오프라인에서 체크해도 기기에 반영하고 나중에 동기화한다.
- 위젯에 다 담기지 않는 투두는 앱으로 이동해 볼 수 있다.
- 표시 순서는 기본적으로 최근 수정 순으로 정하되, 순서 설정 바를 통해 드레그하여 순서 조정이 가능하다.

## 9. 저장, 동기화, 데이터 보호

- 글, 사진, 폴더 구조, 고정 상태, 임시저장, 삭제 시각을 기기에 저장한다.
- 인터넷 연결 없이도 작성·수정·폴더 이동·투두 완료·삭제·복구가 가능하다.
- 인터넷과 iCloud를 사용할 수 있게 되면 같은 Apple 계정의 데이터와 자동으로 동기화한다.
- iCloud를 사용할 수 없는 동안에도 로컬 사용을 막지 않는다. 동기화 대기나 실패 상태는 방해되지 않는 방식으로 알린다.
- 동기화 중 앱을 닫거나 연결이 끊겨도 이미 입력한 내용을 잃지 않는다.
- 여러 기기에서 같은 메모를 동시에 바꿔 충돌할 경우 한쪽 내용을 조용히 버리지 않는다. 양쪽 내용을 복구할 수 있는 사본을 남긴다.
- 앱 자체의 로그인이나 제3자 계정 생성은 요구하지 않는다.

## 10. 디자인 및 품질 기준

- Apple 기본 앱을 참고한 간결한 화면, 읽기 쉬운 글씨, 분명한 터치 영역을 사용한다. 외형을 그대로 복제하기보다 ADHD MEMO의 폴더 휠을 중심 경험으로 만든다.
- 작성 화면과 휠 전환에는 부드러운 움직임을 쓰고, 드롭 성공·취소·오류가 서로 다른 결과로 느껴지게 한다.
- 햅틱은 선택 대상 변경과 확정 시에만 사용해 피로감을 줄인다.
- 작은 화면, 다크 모드, 큰 글씨, VoiceOver, 동작 줄이기 설정을 고려한다.
- 사진 접근 권한을 요청할 때 사용자가 사진 첨부를 선택한 맥락에서 요청한다.
- 폴더가 12개일 때도 한 원형 휠에서 현재 조준한 방향과 폴더 이름이 분명해야 한다. 작은 아이콘 사이에 놓아도 인접 폴더로 잘못 저장되지 않도록 각도 구역과 햅틱을 조정한다.

## 11. 검증 시나리오

구현 완료 여부는 다음 흐름을 실제 iPhone에서 확인한다.

1. 앱을 처음 실행해 바로 글을 쓰고 인사이트에 드롭하면 저장되고 빈 작성 화면이 나온다.
2. 폴더 수가 1·2·3·8·9·12개일 때 페이지 없이 한 원에 배치되고, 상단 11시~1시를 제외한 각도에 따라 올바른 폴더가 선택된다.
3. 미분류 메모에는 11시 임시저장·1시 삭제, 저장된 메모에는 12시 삭제만 표시되며 두 경우의 폴더 위치는 같다.
4. 폴더를 조준할 때 아이콘 확대와 햅틱이 나타나고, 다른 폴더로 이동하면 선택 상태가 바뀐다.
5. 대상 밖에 놓거나 드래그를 중단하면 메모와 내용이 원위치로 돌아온다.
6. 우측 상단 ⋮ 메뉴에 사진 첨부·고정/해제·삭제·설정 중 현재 메모에 맞는 항목만 나타나고, 새 메모 항목은 없다.
7. 새 메모를 11시 임시저장 대상으로 드롭하면 임시저장 목록에 나타나고 빈 작성 화면이 열린다. 저장된 메모에는 임시저장 대상이 나타나지 않는다.
8. 새 메모를 1시 삭제, 저장된 메모를 12시 삭제 대상으로 드롭하면 휴지통으로 이동한다.
9. 작성 도중 앱을 종료한 뒤 재실행하면 최근 임시저장 메모가 복원된다.
10. 임시저장 메모를 폴더에 저장하면 임시저장 목록에서 사라지고 중복 메모가 생기지 않는다.
11. 저장된 메모를 수정하고 현재 또는 다른 폴더로 드롭하면 수정 내용이 저장되고 빈 작성 화면이 열린다.
12. 저장된 메모를 다른 폴더로 드롭하면 원래 폴더에서 사라지고 새 폴더에 나타난다.
13. 30자를 넘거나 줄바꿈·사진이 있는 메모를 투두리스트로 드롭하면 이동이 거부되고 원본이 유지된다.
14. 앱과 위젯에서 각각 투두를 완료하면 즉시 휴지통으로 이동하고 복구 시 미완료로 돌아온다.
15. 사용자 폴더를 삭제·복구하면 그 안의 메모도 함께 이동·복구된다.
16. 삭제 후 30일이 지난 데이터는 영구 삭제된다.
17. 오프라인에서 메모·폴더·투두를 변경한 뒤 연결하면 iCloud와 동기화된다.
18. 검색·고정·사진 첨부가 일반 메모와 폴더 목록에서 올바르게 동작한다.
19. 큰 글씨와 VoiceOver 사용 시에도 폴더를 선택하고 메모를 저장할 수 있다.

## 12. 구현 시 우선순위

1. 데이터 보존과 임시저장, 기본 작성 화면

3. 기본·사용자 폴더와 메모 이동
4. 투두 제한과 홈 화면 위젯
5. 검색·고정·휴지통·복구
